Project Infinity X 4.1 (Android 17) for the Motorola ThinkPhone
Build 2026-10-17  UNOFFICIAL

Fixes in this build
-------------------
- Double-tap to wake works.

- Refresh rate no longer flickers. The panel shifts gamma on rate changes, so
  the framework and the display HAL are both held to the rate you pick.

- Refresh rate is a single choice (60 / 90 / 120 / 144 Hz) instead of a range.

- Always-On Display runs at 60 Hz; the fingerprint sensor still overrides it.

- Status bar is aligned across home, lockscreen and quick settings.

- Stock Motorola Camera is included.

- OTA updates served from this project. The OTA carries the boot chain
  (boot/vendor_boot/dtbo/vbmeta/recovery), so you only need the separate
  images zip for a clean install from stock.

- additional_images-<date>.zip ships the boot chain for first install from
  stock. Flash every image in it before the recovery step.

Known issues
------------
- USB-C port role selection is unreliable.
- "Show taps" can drop the refresh rate in developer options.

Report problems with the build date from Settings > About phone and a logcat.
Dirty flashing over the previous build works; factory reset before reporting
if anything misbehaves.
